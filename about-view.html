About Me

👋

Hello! I am Dhiaz Anggana Ramadhan, an Informatics graduate with a strong passion for game development, web development, and interactive application design. I enjoy transforming ideas into functional and engaging digital products that deliver meaningful user experiences.

During my academic journey, I have developed hands-on experience building 2D platformer games using Unity and C#, as well as web-based applications using PHP, MySQL, HTML, and CSS. I love working on both the technical logic behind the system and the visual aspects of the interface to create applications that are not only reliable but also user-friendly.

I have worked on multiple projects, including developing desktop and Android games such as Dragon Warrior and building a service management website for a laundry business. Through these projects, I strengthened my skills in problem solving, system design, database management, and full-stack development, while also learning how to optimize performance and improve usability.

I am highly motivated to continuously learn new technologies, adapt to challenges, and grow as a developer. My goal is to start my professional career as a Game Developer or Software Engineer, contributing creative ideas and technical solutions to build impactful digital products.
